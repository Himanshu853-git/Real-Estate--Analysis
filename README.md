# Real-Estate analysis
Overview
This project analyzes residential property listings to identify pricing trends, property distribution, and location-based insights.

Tools Used
Python
Pandas
SQL
Seaborn
Excel
Power BI (Learning)

Dataset
1022 property records containing:

Apartment Type
Price
Area
Price per Sq Ft
Status
Location

Data Cleaning
Removed duplicates
Checked missing values
Created Locality and City columns

Exploratory Data Analysis
Property Distribution by City
Property Type Distribution
Price Distribution
Area vs Price Analysis

Key Insights
Dehradun contains the highest number of listings.
3 BHK properties dominate the market.
Property prices generally increase with area.
